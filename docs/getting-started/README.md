# Getting started

This section helps you get the web service or CLI running and configure the dependencies each one needs. The repository includes a sample environment file, but it does not load `.env` automatically.

## Local index

- [Installation](installation.md): requirements and commands to install, build, and start the server or CLI.
- [Configuration](configuration.md): database, Redis, HTTP address, logging, and test environment variables.
- [Command-line interface](cli.md): CLI and server flags, output modes, and exit codes.
