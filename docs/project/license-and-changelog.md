## Changelog

The root [CHANGELOG.md](../../CHANGELOG.md) records unreleased changes and published versions. Add user-visible changes under `## [Unreleased]`; the release workflow reads the newest SemVer section when it creates a release.

See [Release process](../operations/releases.md) for the expected version-heading format and generated release artifacts.
