# Security Policy

## Supported versions

The project does not publish a formal version support matrix. Security reports are assessed individually; fixes or backports to older versions are not guaranteed. Please include the affected version or commit in your report.

## Reporting a vulnerability

Please report suspected vulnerabilities privately using [GitHub's private vulnerability reporting for this repository](https://github.com/lbenicio/goreportcard/security/advisories/new). Do not disclose vulnerability details in a public pull request or other public repository content.

If you cannot access the reporting form, use the [maintainer contact form](https://lbenicio.dev/contact/) to request a private reporting channel. Do not include exploit details in that initial message.

Please allow the maintainers time to investigate and coordinate a fix before making vulnerability details public. The project does not promise a fixed response or disclosure timeline.
